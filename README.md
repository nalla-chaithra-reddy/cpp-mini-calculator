# C++ Mini Calculator

A simple **C++ Mini Calculator** built as a beginner programming project.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Remainder
* Continuous operation using a loop
* Exit option

## Concepts Used

* Variables
* Data types
* Input and output
* Arithmetic operators
* Conditional statements
* Loops
* Functions
* Basic C++ programming

## How It Works

The program displays a menu of available operations.
The user selects an operation, enters two numbers, and the calculator performs the selected calculation.

The calculator continues running until the user chooses the **Exit** option.

## How to Run

### Compile

```bash
g++ calculator.cpp -o calculator
```

### Run

```bash
./calculator
```

## Purpose

This project was created to practice and strengthen my **C++ fundamentals** while building a simple real-world application.
